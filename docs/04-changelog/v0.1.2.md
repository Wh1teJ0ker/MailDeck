# v0.1.2 更新日志

状态:开发中(未发布)

## 变更

- 设计语言整体切换为「玻璃拟态」并按市面优秀实现重做配方:基底先铺**浓色弥散光斑**(黑主题为冷石墨蓝灰系、白主题为蓝紫/青/琥珀柔光,两套同构图仅换色调,保证色调统一),玻璃面改用 **blur(42px) + saturate(165%)** 强配方 + 低透明度 + 内高光(顶部折光线)+ 白描边 + 多层投影;主题收敛为**黑/白两套**(石墨·黑为默认,素白·白可选),每套携带完整 token,切换经 AntD 明暗算法 + CSS 变量全局生效。界面无 emoji。
- 界面组件(侧栏/列表卡片/阅读区/背景/文字色)全部变量化,跟随主题即时切换。
- 应用图标定稿:SVG 精绘「石墨玻璃 M」(透明底、白描边圈、石墨渐变胶囊笔画、顶部玻璃高光、V 交点白点、深灰投影),图标源改为 SVG(scripts/icon-candidates/d-fuse-graphite.svg),gen-icon.mjs 负责 SVG 渲染;全平台尺寸重新生成。
