# v0.1.2 更新日志

状态:开发中(未发布)

## 变更

- 设计语言整体切换为「石墨玻璃」:半透明玻璃层(毛玻璃 backdrop-filter)+ 白色细描边 + 多层投影;主题收敛为**黑/白两套**(石墨·黑为默认,素白·白可选),每套携带完整 token(基底/弥散层/玻璃浓度/描边/文字色),切换经 AntD 明暗算法 + CSS 变量全局生效;玻璃透明度按反馈调实(常规面 0.72-0.74、弹窗/阅读区 0.92-0.94),弥散背景收敛为细腻的明暗渐变。无蓝色基调,界面无 emoji。
- 界面组件(侧栏/列表卡片/阅读区/背景/文字色)全部变量化,跟随主题即时切换。
- 应用图标定稿:SVG 精绘「石墨玻璃 M」(透明底、白描边圈、石墨渐变胶囊笔画、顶部玻璃高光、V 交点白点、深灰投影),图标源改为 SVG(scripts/icon-candidates/d-fuse-graphite.svg),gen-icon.mjs 负责 SVG 渲染;全平台尺寸重新生成。
