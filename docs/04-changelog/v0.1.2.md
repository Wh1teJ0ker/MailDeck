# v0.1.2 更新日志

状态:开发中(未发布)

## 新增(续)

- Gmail 邮箱适配:添加邮箱弹窗选 Gmail 后走 Google 浏览器授权(PKCE),自动读取账号地址、refresh token 入加密凭证库、access token 驻内存自动续期;同步/阅读/已读回写全链路复用现有管线。设置中需填写 Google OAuth 客户端 ID(Google Cloud 创建,测试态限白名单用户)。

## 变更

- 背景系统重做(参考 Sui-IB/InternalBeyond 的雨玻璃语言):整屏氛围画打底(程序化生成的雨痕/水珠/雾团/蝶影/光带 SVG),玻璃面板嵌在画中;**多背景可选**(内置「雨夜」「晨雾」)+ **自定义图片上传**(JPG/PNG ≤10MB,魔数校验,存应用数据目录),上传后可切玻璃色调(深/浅)与任意图片搭配。
- 修复窗口四周白边:根因为项目缺少全局 CSS reset(body 默认 8px margin + 白底);补 html/body reset、#root 高度与深色滚动条。
- 删除旧的「仅配色」弥散方案;玻璃配方对齐参考实现(blur(10px) saturate(1.25) + 118° 斜向反光 + 低透明度描边)。

- 设计语言整体切换为「玻璃拟态」并按市面优秀实现重做配方:基底先铺**浓色弥散光斑**(黑主题为冷石墨蓝灰系、白主题为蓝紫/青/琥珀柔光,两套同构图仅换色调,保证色调统一),玻璃面改用 **blur(42px) + saturate(165%)** 强配方 + 低透明度 + 内高光(顶部折光线)+ 白描边 + 多层投影;主题收敛为**黑/白两套**(石墨·黑为默认,素白·白可选),每套携带完整 token,切换经 AntD 明暗算法 + CSS 变量全局生效。界面无 emoji。
- 界面组件(侧栏/列表卡片/阅读区/背景/文字色)全部变量化,跟随主题即时切换。
- 应用图标定稿:SVG 精绘「石墨玻璃 M」(透明底、白描边圈、石墨渐变胶囊笔画、顶部玻璃高光、V 交点白点、深灰投影),图标源改为 SVG(scripts/icon-candidates/d-fuse-graphite.svg),gen-icon.mjs 负责 SVG 渲染;全平台尺寸重新生成。
