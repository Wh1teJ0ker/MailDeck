# MailDeck

面向个人的多邮箱接收管理桌面工具。

当前处于选型确认完成、准备进入 M1 接入可行性验证的阶段；技术栈已确认为 Rust + Tauri，v0.1.0 首先接入 QQ 邮箱，后续逐步扩展其他邮箱服务商。

## 已确认方向

- 个人使用，集中管理自己的多个邮箱账号。
- 桌面应用形态，账号配置和邮件缓存保存在本机。
- v0.1.0 接入 QQ 邮箱（授权码），多账号统一收件。
- 技术栈：Rust + Tauri v2 + React/TypeScript + SQLite。
