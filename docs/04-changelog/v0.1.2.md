# v0.1.2 更新日志

状态:开发中(未发布)

## 变更

- 设计语言整体切换为「石墨玻璃」:深色石墨基底 + 中性弥散光、半透明玻璃层(毛玻璃 backdrop-filter)、白色细描边、多层投影;AntD 切换暗色算法,主题色预设重排(石墨为默认,天蓝降为可选,新增青碧),界面组件(侧栏/列表卡片/阅读区/背景)全部玻璃化。无蓝色基调。
- 应用图标定稿:SVG 精绘「石墨玻璃 M」(透明底、白描边圈、石墨渐变胶囊笔画、顶部玻璃高光、V 交点白点、深灰投影),图标源改为 SVG(scripts/icon-candidates/d-fuse-graphite.svg),gen-icon.mjs 负责 SVG 渲染;全平台尺寸重新生成。
