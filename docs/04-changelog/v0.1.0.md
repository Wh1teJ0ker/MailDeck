# v0.1.0 更新日志

状态：开发中（未发布）

## 新增

- 建立文档体系：按产品（01-product）、架构（02-architecture）、流程（03-process）、更新日志（04-changelog）分目录组织，含文档导航与维护约定。
- 确认技术栈：Rust + Tauri v2 + React/TypeScript + SQLite；IMAP 走 async-imap，解析走 mail-parser，HTML 清理走 ammonia，凭证走系统凭证库（keyring）。
- 确认 v0.1.0 服务商范围：QQ 邮箱（授权码）。
- MVP 实现落地（Rust + Tauri 2 + React）：QQ 账号添加与授权验证、收件箱同步（UID 增量 + UIDVALIDITY 重建）、统一收件箱三栏界面、正文按需拉取与 ammonia 安全清理（沙箱 iframe 渲染）、已读/未读回写、SQLite 本地存储、keyring 凭证保护、应用图标。
- 测试体系：测试先行且与源码完全分离——Rust 集成测试 `src-tauri/tests/`（mail/store/sync/credentials/provider_qq/provider_registry/update，真实账号用例 `#[ignore]`）、前端 Vitest `tests/`（format/store/api）。
- 按类型添加账号：新增服务商类型注册表（QQ 可用；Outlook、163 预留置灰），添加弹窗按类型选择，新服务商接入只需在注册表登记。
- 设置中心：侧栏设置入口，当前提供检查更新与在线更新（tauri-plugin-updater + 应用内更新签名密钥已生成；更新源暂为占位地址，发布前配置）。
- 完善账号管理：侧栏每个账号提供立即同步、暂停/恢复、编辑（改名与颜色）、移除入口；新增 `update_account` 能力。
- 视觉重构：参考现代邮件客户端设计语言整体重做——浅灰底圆角卡片、品牌渐变蓝主题（选中导航/主按钮/选中邮件卡片/头像均用 135° 蓝色渐变 #3d8bfd→#1554e0）、三栏卡片式布局、HTML/纯文本切换查看。
- 多文件夹支持：同步时自动发现并分类邮箱（收件箱/已发送/草稿/已删除/垃圾箱，SPECIAL-USE 旗标优先、中英文名启发式兜底，IMAP UTF-7 中文文件夹名解码）；侧栏账号可展开文件夹子视图，未读数按邮箱统计；阅读与已读回写按邮件所属邮箱执行。
- HTML 渲染完善：保留邮件 CSS（<style> 块与 style 属性，沙箱 + CSP 双重阻断其外联与脚本）；cid 内嵌图片转 data URI 直接显示（单张上限 4MB）；内嵌图不再计入附件列表。
- 账号管理面板：侧栏新增账号管理入口，集中展示所有账号（状态、最近同步、错误）并可直接同步/暂停/编辑/移除；后续按反馈撤销该面板，管理动作收敛到侧栏账号组（见下条）。
- 一键已读：列表工具栏新增「全部已读」，把当前视图（某文件夹或全部收件箱）的全部未读在服务端与本地同时标已读；按账号复用连接、UID 分块批写（每块 500），单个账号失败不影响其余。
- 设置中心扩展：新增语言切换（简体中文 / English，手写 i18n 模块，词典键位对齐有测试约束，无新增依赖）与主题色切换（极地蓝/青碧/鸢尾紫/蔷薇/琥珀五个预设，经 CSS 变量全局生效，AntD token 同步跟随）；设置持久化到本地（zustand persist）。
- 应用图标重绘：蓝色渐变圆角方 + 立体白信封（翻盖线、投影、顶部高光、四角透明），全平台尺寸重新生成。
- 同步至 GitHub（Wh1teJ0ker/MailDeck，公开；切换前已做敏感产物全量扫描：追踪文件、提交历史均无凭证/真实邮箱/私钥，签名私钥仅存本机与仓库 Secrets）：Release 流水线在打 v* tag 时自动构建 macOS 双架构 dmg、发布 GitHub Release 并产出在线更新源；更新源已指向 GitHub Releases。日常测试与构建检查按反馈撤出远程 CI，改为本地一键校验 `pnpm verify`（前端测试 + 前端构建 + Rust 测试）。
- 侧栏按参考设计重构：去除冗余的「邮箱导航组 + 底部按钮排」，改为「智能视图（全部邮件/未读）+ 按账号分组树」——组头（头像 + 名字 + 折叠箭头 + ⋯ 菜单）下为同步状态行与该账号的文件夹列表，添加账号收敛为分组标题行的 + 按钮，设置入口移至列表顶栏右侧。
- 阅读区信息补全：增加收件人、所属账号标签、所在文件夹、完整时间。
- 问题修复：列表同步误用 HEADER.FIELDS 段导致全列表"未知发件人"（async-imap 不解析该段，改抓完整 HEADER）；打开正文未先 SELECT 邮箱导致"服务器上未找到该邮件"；ColorPicker 表单值字符串/对象双形态导致的提交崩溃。
- 存储层升级 schema v2：邮件挂到邮箱维度（唯一键 mailbox_id+uidvalidity+uid，同步游标移至邮箱行），旧库打开时自动迁移且邮件数据保留。
- 技术栈补齐定型：前端配套（Ant Design 5、TanStack Query / TanStack Virtual、Zustand、tauri-specta、Vitest）、检索方案（FTS5 + trigram）、首发平台（macOS，Apple Silicon 优先）与分发策略（Tauri bundler，签名公证 M4 决定）。

## 变更

- 技术栈候选由 Electron 调整为 Rust + Tauri，对比记录与理由见 [TECH_STACK.md](../02-architecture/TECH_STACK.md) 第 2 节。
- v0.1.0 服务商范围曾计划扩展至 Outlook，确认回调为仅 QQ；Outlook 转入后续版本服务商候选，见 TECH_STACK.md 决策记录。
- 样式与组件方案由 Tailwind CSS + shadcn/ui 改为 Ant Design 5（含 @ant-design/icons），其余前端配套不变。
